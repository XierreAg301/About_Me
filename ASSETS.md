## NASA space reference

The environment uses a 2048×1024 JPEG derived from NASA Goddard’s full 4K OpenEXR Deep Star Maps 2020 product. The source visualization plots the position, brightness, and color of approximately 1.7 billion stars using Hipparcos-2, Tycho-2, Gaia DR2, and supporting catalogs.

Credit:

> NASA/Goddard Space Flight Center Scientific Visualization Studio. Gaia DR2: ESA/Gaia/DPAC.

NASA media and reproduction guidelines apply.

The globe surface uses NASA Earth Observatory's 3600×1800 Black Marble 2016 color map. It is a standard equirectangular Earth image, so the runtime `world-atlas` borders and country anchors use the same geographic coordinate system instead of trying to match the marketplace model's stylized painted continents.

Earth image credit:

> NASA Earth Observatory image by Joshua Stevens, using Suomi NPP VIIRS data from Miguel Román, NASA Goddard Space Flight Center.

## Globe processing

The downloaded continent shell stopped before the north pole and exposed the inner sphere as a large circular hole. The asset pipeline replaces that damaged shell with a complete 96-segment UV sphere. At runtime, the stylized source texture is replaced by the georeferenced NASA Black Marble surface so the imagery and data-driven borders align in Asia.

The pipeline also:

- Removes the marketplace scene’s baked artistic rotations.
- Rebuilds the globe in a standard latitude/longitude orientation.
- Preserves and restyles the inner ocean and holographic grid layers.
- Exports the browser-ready result as `digital-globe.glb`.

Pointer interaction is handled by a separate low-poly invisible sphere. The detailed globe meshes and both border layers are excluded from raycasting, preventing pointer movement from repeatedly testing tens of thousands of outline segments.

Political borders and coastlines are generated at runtime from:

| Package/data | Usage | License |
| --- | --- | --- |
| `world-atlas` | 50m country topology for refined coastlines and internal borders | ISC |
| `topojson-client` | Separates topology into coastline and political-border meshes | ISC |
