# Aaron Austin C. Amaro — Portfolio World

An accessible cyber-space portfolio built with React, Vite, Tailwind CSS, and
React Three Fiber.

The seven portfolio sections remain complete semantic HTML. A single
lazy-loaded WebGL node world enhances navigation when the device supports it;
reduced-motion and no-WebGL visitors receive the equivalent CSS/SVG map.

## Commands

```bash
npm run dev
npm run lint
npm run build
npm run preview
```

Vite uses `/About_Me/` for the GitHub Pages build and `/` when the `VERCEL`
environment variable is present.
